## 我在做的事

**科研与证据**

围绕具体科学问题，把文献、数据、分析和图表连起来。区分观察、推断与验证，让每一步都能追溯。

**工具与工作流**

先用成熟工具，再补真正缺少的部分。关注的终点是能在真实工作中使用的结果。

**知识与创作**

分享文献阅读、数据分析和科研工具的使用经验。

欢迎在对应项目的 Issues 里交流具体问题、使用体验和改进建议。
